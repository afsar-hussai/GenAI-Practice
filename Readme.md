# ☕ GenAI with Python: Chai aur Code Journey

This repository is a collection of my projects and experiments while following **Hitesh Choudhary's Full Stack GenAI course**. My goal is to master the art of building production-grade AI applications, focusing on LLM orchestration, Agentic workflows, and efficient RAG pipelines.

> *"Building with the new tech, one cup of chai at a time."*

## 🎯 Learning Objectives
- **LLM Orchestration:** Mastering LangChain and LangGraph for complex AI logic.
- **RAG & Vector DBs:** Implementing advanced retrieval using Qdrant, Pinecone, and PGVector.
- **Agentic Workflows:** Moving from simple chatbots to autonomous AI agents using LangGraph.
- **Production AI:** Implementing Guardrails, PII protection, and observability with Langsmit/Langfuse.

---

## 🛠️ Tech Stack (The Hitesh Style)
- **Primary Language:** Python 🐍
- **LLMs:** OpenAI (GPT-4), Google Gemini, Llama 3 (via Groq/Ollama)
- **Frameworks:** LangChain, LangGraph, Hugging Face
- **Databases:** Qdrant (Vector Store), Neo4j (Graph), PostgreSQL
- **Backend/Deployment:** FastAPI, Docker, AWS
